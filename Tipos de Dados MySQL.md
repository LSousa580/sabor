Tipos de Dados MySQL
- INT (numeros Inteiros): Idade
- DECIMAL (numeros Decimais): Altura, Peso
- CHAR/VARCHAR (caracteres): Email, Senhas, Nome 
- FULLTEXT/TEXT (textos longos): Postagens, Artigos e etc..
- DATE/TIME/DATETIME/TIMESTAMP: Data e hora 
- BIT/BITMAP/SET/ENUM
- BOOLEAN (lógico): Verdadeiro ou Falso
- JSON : "Dados extraíveis" 
- ARRAY : "Lista" de objetos
- UUID: Identificador único para cada item
